# Search visibility
The homepage targets a free Premier League prediction game with friends and explains scoring, private leagues and bots.
Completed match reviews and fixtures up to 14 days ahead are eligible for indexing. Other fixtures remain available for play but use noindex,follow and omit premature form previews. The sitemap applies the same policy. Eligibility is evaluated at request time, so pages become indexable automatically without redeployment.
The guide directory promotes near-term and historical guides. All game fixtures remain available through fixtures and club pages.
Run php tests/test_seo_policy.php to verify the horizon policy. Deploy seo-policy.php together with public.php and sitemap.php.
Measure in Google Search Console: compare the latest 28 days with the previous 28, segmented by query and landing page. Track impressions, clicks, CTR and average position for game-with-friends terms and brand terms separately. Inspect homepage, a current preview and a completed review; confirm Google's chosen canonical and last crawl. Submit sitemap.xml and request indexing for a small set of important updated pages. Do not remove intentional account/private-league noindex directives.
A smaller sitemap is prioritisation, not a guarantee of rankings. Changes require recrawling and search performance can vary.
